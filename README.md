This is simply an updated/extended version of the original tool made by AeolusUX which can be found here: https://aeolusux.github.io/ArkOS-R3XS/tools/dtbIdentify.htm

All I basically did (as you can see in the source of the dtbIdentify.htm, is adding some additional information and direct links (zips) to the screen files users will need for their R36S or R36H.
I did <strong>not</strong> change any 'technical functions' (or detection/recognition functions) of the tool, only added lots of information and links for the end-user.

This is just done to make it a bit more easier for beginners or people who follow my tutorial on how to install ArkOS on their R36
